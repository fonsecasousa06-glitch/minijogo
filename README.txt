Esse projeto é só um passa tempo meu pois queria experimentar
programar um jogo do zero no terminal do bash. A ideia por
enquando, devido a minha falta de conhecimento, é fazer uma
espécie de walk simulator com alguns puzzles e habilidades, co-
mo o dash desse jogo, bem simples para depois começar a adicio-
nar mecânicas de RPG, como batalhas em turnos, inimigos que se
movem com uma certa inteligência, algo por esse caminho.

Os comandos basicos são
Setas para andar
Q para sair
E para interagir(você vai sempre interagir na última direção
que você tiver apertado)
1 a 5 para usar os itens do inventário

Um detalhe a se tornar é que as teclas WASD andam tambem,
mas as teclas A e D estão trocadas pois se eu fizesse elas
do jeito certo as setas direita e esquerda ficariam trocadas
e eu prefiro usar as setas, então desculpe se isso estragar
sua experiência.
